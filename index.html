What it handles

Useful operations, with the boundary visible.

This plugin works with accessories already exposed by Homebridge. It does not reach into native HomeKit devices that Homebridge cannot see.

01

Accessory control

List, filter, switch, dim, and schedule existing lights, switches, and outlets.

02

Health and watchdogs

Review service state and logs on demand or on a configured daily schedule.

03

Messaging

Use Telegram or ntfy for two-way control and Discord webhooks for notifications.

04

Approved commands

Run named shell commands only after they have been added to the allowlist.

Safety model

The model proposes. Deterministic code enforces.

Device identifiers must match Homebridge’s current inventory. Shell commands must match an approved skill. Cooldowns and daily quotas are checked before execution, and newly proposed skills stay pending until a person approves them.

Read the complete safety model →
  • No arbitrary shell accessOnly configured command IDs can run.
  • Explicit approvalModel-proposed skills begin in a pending state.
  • Rate limitsCooldowns and daily quotas apply to recovery actions.
  • Redacted configurationKnown token and webhook fields are masked in chat output.
